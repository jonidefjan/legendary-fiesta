Selected work

Case studies from Wescore, an e-commerce and corporate benefits platform. The code belongs to the client, so I describe the problem, what I changed and the outcome.

7.6 sp95 image load

Slow images on the storefront

Each session loaded about 110 images, and the Chrome DevTools trace recorded 290 resources per page load. At p95, images took 7.6 s. I measured it, isolated the bottleneck and fixed it with lazy loading, Next.js Image, caching, compression and an Azure CDN, without touching the data architecture.

About 40% less data transferred per session.

88kproducts in the catalog

One catalog, many suppliers

I integrated more than 88,000 products from supplier APIs that all work differently, including Casas Bahia, Extra and Ponto Frio. Every white-label store reads that catalog in real time.

3security layers

Passed an external pentest

The platform went through an external penetration test with the protection layers I implemented.

Transport

  • HTTPS/TLS in every environment
  • CSP, HSTS and other headers
  • CORS restricted per environment

Session

  • JWT with refresh token rotation
  • OAuth2 / SSO
  • Email-based MFA

Application

  • Role-based access control
  • CSRF and XSS protection
  • Zod validation and rate limiting
